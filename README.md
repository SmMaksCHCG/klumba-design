# Дизайн-проект клумбы

Картинки смешанного цветника: визуализация и план посадки.

В составе: 2 куста пиона, 3 лилии, флокс, лаванда, гладиолусы, анютины глазки, низкая гвоздика, эхинацея и шалфей.

## Как запустить

```bash
npm install
npm run dev
```

Страница откроется на [http://127.0.0.1:43147](http://127.0.0.1:43147).

Исходные изображения лежат в `public/klumba-visualization.png` и `public/klumba-plan.png`.
